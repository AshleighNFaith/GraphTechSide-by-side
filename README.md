# GraphTechSide-by-side
As part of the IsADatatThing YouTube Cahnnell Internship program, interns will work in various graph tech, the data and READMEs will be here.

The Use Case: You've just been hired as the first data engineer at a new film studio. Before the studio greenlights a project, leadership wants a data-backed answer to one question: "can we predict which combinations of actors and directors actually tend to produce well-reviewed films for proposed cast/director lineup for projects?" Your job is to build a knowledge graph of people, movies, and critic scores that can surface repeat collaborators, measure how well their pairings score, and flag which lineups look "bankable." You will build the same graph eight times (or however we can get through), once per database, to see how each one handles trend-detection and prediction-flavored queries.

What we will test for each graph database:
-For each tool, the intern will:
-Load the same set of instance data
-Update some of the instance data
-Do one example of data cleanup
-Load a data model
-Update a model
-Run the same inference / Graph query
-If it has AI abilities, use them in an example
